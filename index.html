1. Introduction

Association Rule Learning is an unsupervised machine learning technique used to identify relationships, patterns, and associations among items in a dataset. It is commonly used to discover which products are frequently purchased together.

For example, a supermarket may discover that customers who purchase diapers often purchase beer as well. This information can help the business improve product placement, promotions, and recommendations.

2. Description and Working

Association rules are written in the following form:

{Diapers} → {Beer}

This rule means that a transaction containing diapers is associated with a transaction containing beer. It describes a pattern, not proof that buying one product causes someone to buy another.

Steps involved

  1. Collect transaction data from customers.
  2. Identify the items appearing in each transaction.
  3. Calculate item frequencies and support.
  4. Generate possible association rules.
  5. Calculate confidence and lift for each rule.
  6. Identify useful rules and interpret the results.

5. Important Formulas

A. Support

Support measures how often the items in a rule appear together in all transactions.

Support(A → B) = Transactions containing A and B ÷ Total transactions

For Diapers → Beer:

Support = 4 ÷ 10 = 0.40 = 40%

B. Confidence

Confidence measures the proportion of transactions containing A that also contain B.

Confidence(A → B) = Support(A and B) ÷ Support(A)

Diapers appear in 5 transactions, and 4 of these also contain beer.

Confidence = 4 ÷ 5 = 0.80 = 80%

C. Lift

Lift compares the confidence of a rule with the overall frequency of its consequent.

Lift(A → B) = Confidence(A → B) ÷ Support(B)

Beer appears in 4 out of 10 transactions.

Lift = 0.80 ÷ 0.40 = 2.00

Meaning of lift

  • Lift greater than 1: Positive association.
  • Lift equal to 1: No association beyond the baseline frequency.
  • Lift below 1: Negative association.

These measures describe patterns in observed transactions. A high lift alone does not prove causation or guarantee that a rule will be useful in business.

6. Apriori Algorithm

Apriori is a widely known algorithm for discovering frequent itemsets and generating association rules. It uses the principle that if an itemset is frequent, all its non-empty subsets must also be frequent.

  1. Set a minimum support threshold.
  2. Find individual items meeting the threshold.
  3. Combine frequent items to generate candidate itemsets.
  4. Remove candidates that do not meet minimum support.
  5. Generate association rules and evaluate confidence and lift.

For larger datasets, algorithms such as FP-Growth can also be used to find frequent patterns efficiently.

7. Python Implementation

The following code uses the same transactions to calculate the four example rules and generate graphs. It uses pandas and mlxtend.

Install the required libraries:

pip install pandas mlxtend matplotlib
import pandas as pd
import matplotlib.pyplot as plt
from mlxtend.preprocessing import TransactionEncoder
from mlxtend.frequent_patterns import apriori, association_rules

# Market basket transaction dataset
transactions = [
    ['Bread', 'Milk'],
    ['Bread', 'Diapers', 'Beer', 'Eggs'],
    ['Milk', 'Diapers', 'Beer', 'Cola'],
    ['Bread', 'Milk', 'Diapers', 'Beer'],
    ['Bread', 'Milk', 'Diapers', 'Cola'],
    ['Bread', 'Butter'],
    ['Bread', 'Milk', 'Butter'],
    ['Milk', 'Butter'],
    ['Bread', 'Milk', 'Diapers', 'Beer'],
    ['Bread', 'Eggs']
]

# Convert transactions into a one-hot encoded table
encoder = TransactionEncoder()
encoded = encoder.fit(transactions).transform(transactions)
basket = pd.DataFrame(encoded, columns=encoder.columns_)

print("Transaction dataset:")
print(basket.astype(int))

# Find frequent itemsets
frequent_items = apriori(
    basket,
    min_support=0.10,
    use_colnames=True
)

print("\\nFrequent itemsets:")
print(frequent_items)

# Generate association rules
rules = association_rules(
    frequent_items,
    metric="confidence",
    min_threshold=0.20
)

# Display useful columns
print("\\nAssociation rules:")
print(rules[
    ['antecedents', 'consequents',
     'support', 'confidence', 'lift']
].round(3))

# Product frequency chart
basket.sum().sort_values(ascending=False).plot(
    kind='bar',
    title='Product Frequency in Transactions',
    color='#9270d8'
)
plt.ylabel('Number of Transactions')
plt.xlabel('Product')
plt.tight_layout()
plt.show()

# Show the strongest rules by lift
top_rules = rules.sort_values(
    'lift', ascending=False
).head(10)

labels = [
    f"{', '.join(a)} -> {', '.join(c)}"
    for a, c in zip(
        top_rules['antecedents'],
        top_rules['consequents']
    )
]

plt.figure(figsize=(10, 5))
plt.barh(labels, top_rules['lift'], color='#9270d8')
plt.xlabel('Lift')
plt.title('Top Association Rules by Lift')
plt.gca().invert_yaxis()
plt.tight_layout()
plt.show()

The Python code generates rules from the dataset rather than hard-coding the four example rules. Since it uses a small sample and a low support threshold, additional rules may appear in its output.

8. Real-World Applications

RetailDiscover products frequently bought together.
E-commerceRecommend related products to customers.
HealthcareExplore co-occurring patterns in suitable clinical datasets.
BankingExplore relationships between customer service usage patterns.

Advantages

  • Finds patterns without requiring a labelled target variable.
  • Produces rules that can be interpreted by people.
  • Can support recommendations and business decisions.

Limitations

  • Large datasets can produce too many rules.
  • Rare patterns may be missed if support thresholds are too high.
  • Association does not establish cause and effect.
  • Results may change when the dataset or customer behaviour changes.

9. Conclusion

Association Rule Learning is an important unsupervised machine learning technique for identifying relationships among items. Using market basket analysis, we calculated support, confidence, and lift to understand product-purchasing patterns.

In this illustrative dataset, the rule Diapers → Beer has 40% support, 80% confidence, and a lift of 2. This means the two products occur together more often than expected from the overall frequency of beer in these transactions. However, the dataset is small, so the pattern would need to be tested on more data before making business decisions.

Learning outcome: Understand how transaction data can be transformed into meaningful association rules using Python.
